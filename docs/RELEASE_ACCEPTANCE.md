## 运行包与边界

发布包默认凭据为空，Agent 默认关闭。隔离解压验证默认 MD+HTML、仅 MD、仅 HTML 三种输出，删除临时配置后离线重建逐字节一致；原始请求与自评保留，隐私扫描通过。ZIP 和 SHA256SUMS.txt 提供校验。

正式发布仅表示以上工具验收通过。Agent 结果不认证业务质量；图片协议通过不代表识别准确率；音频支持取决于具体模型和服务。保留既有 1.10.2 预发布资产，不覆盖旧包。
